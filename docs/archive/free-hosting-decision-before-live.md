- `bootstrap.py --ipv6` generates a dual-stack Docker bridge and memory/process limits for the 1 GiB host. Root/OS/local-filesystem/permissions/security/readiness/restart/recreation/systemd/corruption safeguards remain. Real VM memory load, NAT66 API egress and reboot remain separate gates.
- `duckdns-update.py --ipv6-only --ipv6 <actual-address>` clears stale records then publishes AAAA through the documented [DuckDNS API](https://www.duckdns.org/spec.jsp). Run it from the trusted IPv4-capable operator environment: DuckDNS's update endpoint currently publishes no AAAA. An interrupted clear/publish must be retried; neither HTTP OK nor a Caddy configuration validates external HTTPS.
- GCS uses workload identity through metadata, no exported service-account key. Backup principal gets ciphertext create/read permissions on its dedicated private bucket, no delete or project-wide storage role. Configure rclone `env_auth=true` and `bucket_policy_only=true` as documented by [rclone](https://rclone.org/googlecloudstorage/). `offsite.py` encrypts before leaving the host; set its prefix ceiling to 4,000,000,000 bytes, then check whole-account storage/requests/egress. No remote history is deleted automatically. Recovery needs the independent owner-held age identity and signing key and an actual isolated restore.
