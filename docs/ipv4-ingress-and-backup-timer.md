# Trial ingress and scheduled encrypted backups

The optional Cloud Run ingress uses the pinned Caddy image with request-based billing, minimum zero instances, maximum one instance, no startup CPU boost, and a private Direct VPC route to the persistent VM. It creates no public VM IPv4, NAT, connector VM or load balancer. It stores neither SQLite nor disaster source files. Trial credit is temporary; this is **TEMPORARY FREE — NOT SUSTAINABLE**, not a guarantee of unlimited free requests or global egress.

`infra/cloud-run-bridge.Caddyfile` requires the observed provider hostname, existing DuckDNS hostname and private VM address. It validates upstream TLS against the DuckDNS certificate, rejects foreign origins before mapping the single permitted origin, removes spoofable forwarded headers, and preserves host-only secure application cookies. No TLS verification is disabled. A real authenticated ingress probe rejected TLS 1.0/1.1 and accepted trusted TLS 1.2 over IPv4. The synthetic Docker rehearsal exercises trusted private TLS, origin ordering, hostile Host/Origin rejection, forwarding-header removal and HSTS. Live application security and IPv4 acceptance remain separate gates.

`infra/scheduled-offsite.py` consumes owner-authorized mode-0600 `secrets/offsite.json` containing only `destination`, public age `recipient`, and `max_remote_bytes` (at most 4,000,000,000). The owner recovery identity must never be placed on this host. The existing rclone configuration supplies private workload authentication. Installation enables a bounded hourly systemd timer; it does not claim an upload or restore succeeded. Each execution refuses a write latch, invalid trial evidence, stale signed source backups and low disk headroom. Existing bounded rclone retries and an overall timeout prevent retry storms. No remote backup history is automatically deleted.

An actual upload/download hash check is recorded privately. Independent signature/decryption/isolated restore still requires the separately escrowed owner-side recovery identity. A bucket in the trial account cannot alone protect against loss of that account. Continuous independent transport and accountable recovery custody remain distinct commissioning gates.
